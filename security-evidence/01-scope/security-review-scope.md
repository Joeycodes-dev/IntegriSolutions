\# IntegriSolutions Security Review Scope



\## Components



The security review covers:



\- Backend API (`backend/`)

\- Web application (`apps/web/`)

\- Mobile application (`apps/mobile/`)

\- Firmware (`firmware/`)

\- Authentication and authorisation

\- Role-based access control

\- Database and API security controls

\- Dependency security

\- Secret and configuration management

\- Evidence integrity controls

\- Deployment/runtime configuration



\## Supporting Configuration



The review also considers:



\- `.github/`

\- `.gitignore`

\- Root package configuration

\- Backend runtime configuration

\- Web/mobile environment configuration



\## Review Objectives



1\. Verify authentication mechanisms.

2\. Verify authorisation and role boundaries.

3\. Identify vulnerable dependencies.

4\. Identify exposed secrets or unsafe configuration.

5\. Assess application and firmware security risks.

6\. Record identified risks and mitigations.

7\. Produce security review evidence.



\## Evidence Location



All review evidence is stored under:



`security-evidence/`
